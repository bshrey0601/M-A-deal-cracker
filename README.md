# M&A Deal Cracker

A web app for analysing a merger or acquisition between two listed companies: it pulls live market data and reported financials for the target and acquirer, then walks through WACC, precedent transactions, a DCF with sensitivity analysis, deal structuring (accretion/dilution, synergies, purchase price allocation), and an AI-written investment thesis you can export to PDF.

🔗 Live demo: [m-a-deal-cracker.onrender.com](https://m-a-deal-cracker.onrender.com/)

## What it does

| Module | What you get |
| --- | --- |
| **Fetch & Verify** | Live price, market cap, LTM revenue, EBITDA, EBIT, net income, D&A, CapEx, net debt and multiples from Yahoo Finance. Every company card shows the data source, quote time and any caveats (e.g. currency conversion, missing fields). |
| **Financial Modeling** | WACC build-up (CAPM with Damodaran industry betas and country risk premia). |
| **Market Cross-Check** | Benchmarks the offer against a curated set of precedent transactions. |
| **AI Deal Engine** | 5-year unlevered DCF with bear/base/bull scenarios and a WACC × terminal-growth sensitivity grid. Tax rate, D&A and CapEx are editable and flow through every cell. |
| **Deal Structuring** | Cash/stock mix, financing cost, synergies with realisation rates, PPA (goodwill, intangibles, amortisation) and pro-forma EPS accretion/dilution with a sensitivity table. |
| **Thesis & Review** | Board-style investment memo written by an LLM from the model's figures, exportable to PDF. |

### About data accuracy

- Market data and fundamentals come from **Yahoo Finance** via the [`yahoo-finance2`](https://github.com/gadicc/yahoo-finance2) library. Quotes may be delayed by up to ~15 minutes depending on the exchange. Yahoo has no official API, so if Yahoo changes its site the fetch can fail until the library is updated (`npm update yahoo-finance2`).
- Fundamentals are trailing-twelve-month figures where Yahoo provides them; D&A and CapEx come from the latest annual cash-flow statement. When a field is missing the app says so on the company card instead of making a number up.
- For cross-listed companies whose statements are in another currency (e.g. ADRs), financials are converted to the trading currency at the live FX rate, and the card shows the rate used.
- If live data can't be fetched, you can choose **Use AI estimate**. Those figures are generated by an LLM, are **not verified**, and are clearly labelled as estimates everywhere they appear. Do not rely on them for real decisions.
- The model outputs are only as good as the inputs and assumptions. Always verify key figures against the company's filings (10-K / annual report) before using them.

## Run it locally

**Prerequisites:** Node.js 22 or newer and npm.

```bash
git clone https://github.com/bshrey0601/M-A-deal-cracker.git
cd M-A-deal-cracker
npm install
cp .env.example .env      # then add GROQ_API_KEY if you want the AI thesis
npm run dev
```

Open http://localhost:3000. Try tickers such as `AAPL` / `MSFT`, or `RELIANCE.NS` / `TCS.NS` for NSE-listed companies (Yahoo symbol format: `.NS` NSE, `.BO` BSE, `.L` London, `.T` Tokyo, `.HK` Hong Kong).

To run the production build locally:

```bash
npm run build
npm start
```

### Environment variables

| Variable | Required? | Purpose |
| --- | --- | --- |
| `GROQ_API_KEY` | Optional | Enables the AI investment thesis and the "Use AI estimate" fallback. Get a free key at [console.groq.com/keys](https://console.groq.com/keys). Without it, everything except those two features works. |
| `PORT` | Optional | Port to listen on (default `3000`). |

Never commit your `.env`; it is already in `.gitignore`.

### Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Dev server (Express + Vite with hot reload) on port 3000 |
| `npm run build` | Builds the frontend into `dist/` |
| `npm start` | Serves the production build and API |
| `npm test` | Unit tests for the DCF, accretion/dilution and market-data mapping |
| `npm run lint` | TypeScript type check |

## Deploy to Render

The repo includes a `render.yaml` blueprint.

1. In Render, choose **New → Blueprint** and connect this repository (or **New → Web Service** with build command `npm ci && npm run build` and start command `npm start`).
2. Set `GROQ_API_KEY` under **Environment** if you want the AI thesis.
3. Deploy. Health check: `/api/health`.

Any Node 22 host works the same way: run `npm ci && npm run build`, then `npm start`; the server reads `PORT` from the environment.

## Tech stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS 4, Motion, jsPDF + html2canvas
- **Backend:** Express (serves the app and proxies data/AI calls so keys stay server-side)
- **Data:** Yahoo Finance (`yahoo-finance2`)
- **AI:** Groq (`llama-3.1-8b-instant`) for the thesis narrative

## Project structure

```
server.ts                  Express server: /api/market/:ticker, /api/ai/*, static hosting
src/
  App.tsx                  Shell and panel routing
  context/DealContext.tsx  Shared deal state
  components/panels/       Fetch, WACC, Precedents, DCF, Deal Structuring, Thesis
  lib/dcf.ts               DCF engine (shared by scenarios and sensitivity grid)
  lib/accretion.ts         Accretion/dilution, synergies, PPA
  lib/marketData.ts        Maps Yahoo Finance responses to the app's data model
  services/dataService.ts  Client calls to the server API
  constants.ts             Industry betas, country risk data, precedent deals
render.yaml                Render deployment blueprint
```
